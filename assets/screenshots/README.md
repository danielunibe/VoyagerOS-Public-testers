# Product screenshot checklist

No current VoyagerOS interface screenshots are included in this directory. The official brand emblem in assets/brand is not a product screenshot.

Older archived images show an earlier beta or QA fixture screens. They were excluded because they do not prove the current product experience. The native app was not available for capture in this review, and the project owner chose to continue without screenshots.

## Capture these real views from one accepted candidate

1. **Desktop overview** — show the native desktop and established dark Dock in their ordinary state.
2. **Dock and navigation** — show a real pointer interaction and the visible navigation surface.
3. **Window management** — show an actual window arrangement or grouping supported by the candidate.
4. **Settings and personalization** — show the current native settings surface and one real persisted preference.

Capture Aurora only after it passes real microphone and target-application QA.

## Before adding an image

- Record the exact candidate version and capture date in the image caption.
- Capture from the unmodified native application; do not compose a fictional screen or replace product controls.
- Remove or obscure names, paths, notifications, account details, and private desktop content.
- Keep the final image readable at GitHub README width and add descriptive alt text.
- Confirm the image depicts the same version described by the release notes.
